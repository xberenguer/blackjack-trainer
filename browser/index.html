About this preview

Virtual chips only. This standalone browser uses the fresh Rust game, renderer, training and two-button recognizer compiled directly to WebAssembly. The display is 240 × 135 pixels. Audio starts after a button gesture.

Settings and exact training totals are saved locally when browser storage is available. Old V1–V8 totals migrate automatically. Resume session is off by default; enable it in Settings to save active hands, pending practice and session analysis privately on this browser. Each load starts in mode Off; only choosing Resume saved session restores its saved live mode. A new session starts fresh in mode Off.

Optional action EV uses an infinite replacement model and bounded funded split analysis, not the hidden shoe. This browser preview is software evidence; the physical display, buttons and speaker still require device validation.
