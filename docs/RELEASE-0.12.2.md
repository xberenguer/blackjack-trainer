# 0.12.2 — StickS3 themes and live card-back previews

On StickS3, **Settings → Display → Background** switches between Blue and Black. Blue remains the default. Waveshare starts in Black and also offers Blue, Green and Red.

On both devices, **Settings → Display → Card back** opens a preview of the actual card. Tap Grey on StickS3 or Right on Waveshare to cycle Gold, Red and Blue. Tap Blue or Left to finish. The selected back appears on face-down cards at the table. Both appearance settings are saved.

Public Save V13 keeps the 2,636-byte packet and preserves earlier preferences, training scores and compatible private checkpoints. Earlier compact saves start with the original Blue background. The browser uses the same display settings as StickS3.
