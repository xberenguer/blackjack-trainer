# 0.12.3 — Shared background and card-back colors

- StickS3 now offers **Green** and **Red** backgrounds alongside **Blue** and **Black**. Waveshare and StickS3 have the same choices, with Black and Blue as their respective defaults.
- Both devices add a **Charcoal** card back. Open **Settings → Display → Card back** to preview the gray and black Stardust pattern before returning to the table.
- Save V14 keeps the same packet size and reads earlier saves, preserving existing colors, preferences, scores and supported resume checkpoints.
