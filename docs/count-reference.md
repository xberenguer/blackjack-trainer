# Optional Hi-Lo reference

Hi-Lo is the default strategy for new installations. Training → Strategy selects the named BJA2018 Hi-Lo index policy or Basic. Basic, when selected, keeps rule-specific basic strategy even when the optional count display is visible. Guide defaults to showing RC+TC; the other modes have their own independent display setting. Count display and choice of recommendation policy are separate controls.

The Rust policy layers the numeric/red playing-index overrides in Blackjack Apprenticeship's 2018 [H17 chart](https://www.blackjackapprenticeship.com/wp-content/uploads/2019/07/BJA_H17.pdf) and [S17 chart](https://www.blackjackapprenticeship.com/wp-content/uploads/2019/07/BJA_S17.pdf) over the verified basic-strategy grids. Both original chart pages were visually inspected. This is a named published index policy, not an exact remaining-composition optimizer.

Unindexed cells keep the verified rule-specific basic policy, including the S17 soft18-versus2 cell. Legal pair recommendations precede ordinary hard-total indexes. The original 8,8 pair exceptions therefore remain distinct from a nonpair hard16. Applicable late-surrender index decisions precede hard Hit/Stand indexes. Missing double/split/surrender legality falls back to the basic legal action.

BJA's [conversion guide](https://www.blackjackapprenticeship.com/true-count-conversion-guide/) specifies dropping the fractional portion. This implementation divides exposed RC by physical undealt decks, then truncates toward zero using integer arithmetic. For example, RC−1 with two decks remaining gives a raw TC−0.5 and an index of 0. A displayed decimal TC can differ from the integer used by the policy. Floor is a different convention and is not silently substituted.

The charts' zero exceptions use the sign of the running count: strictly positive or strictly negative. They do not mean a rounded integer TC threshold at zero. Other integer thresholds are inclusive. The original S17 surrender index for15 versusace is +2; the H17 index is -1. These values were checked visually rather than inferred from a differently formatted text extraction.

The policy interface accepts a visible hand/upcard, legal mask, supported Rules and exposed-card count context. It accepts no engine, hidden burn/hole face or future card order. Invalid count context returns no integer index and falls back to legal basic advice. Insurance applies the published +3 threshold and actual affordability. Showing help, count aids or current-context references retains assistance so it cannot improve unassisted accuracy.

Current Rust evidence: `tests/deviations.rs` covers primary H17/S17 boundaries, negative truncation, strict RC-zero exceptions, surrender/pair priority and insurance funding. Its broader enumeration checks 2,271,360 legal contexts; that enumeration is legality evidence, not an independent proof of each index's optimal EV. The basic chart has 10,058,880 independent comparisons. App controller tests cover aid visibility, immutable attempts, Guide count defaults and mode switching. Native/WASM integration and actual device Guide switching have passed; physical button feel and speaker quality remain distinct observations.
